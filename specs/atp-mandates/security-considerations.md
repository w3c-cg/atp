# Security review checklist (proposed)

Verify root issuer authorization independently of requester claims. Holder proof is not workload attestation. Bind action, resource, audience, grant version, nonce and validity; reject substitution and replay. Verify full delegation chain and reject escalation, cycles and invalid ancestors. Enforce resource access outside the requesting agent; test direct bypass. Define authenticated status freshness and outage behavior, and measure the revocation/commit race. Test concurrent aggregate limits and approval consumption. Distinguish decision receipts from resource-confirmed outcomes. Minimize sensitive identifiers and evidence disclosure. Define algorithms, canonicalization, status rollback handling and unsupported-critical-field rejection before wire conformance. These are review requirements, not completed security assurance.
